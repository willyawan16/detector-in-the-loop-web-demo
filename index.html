Matching is greedy one-to-one in descending score order, class-agnostic, on intersection over union — the COCO rule.

Other examples where curation helps

Every image where the curated model beats the baseline, in one of three ways. A defect counts as found when any prediction above the operating point overlaps it at all, and a false positive counts only when a prediction overlaps no annotation — so in both directions a detection that is visually right but fails IoU still counts as a hit, not an error. The badge is the margin: +n ▲ defects found · +0.nn confidence · −n ✕ false positives dropped.
